# 模拟芯片按类别的 Pin2Pin 重点对比维度

> 目标：避免用一张泛化参数表比较所有模拟芯片。先从 datasheet 识别芯片类别，再输出只影响该类别替代结论的硬性核验项。本文结合本地 TI/ADI/思瑞浦资料的选型结构整理；原始 PDF 不复制进仓库。

## 本地资料观察

本地目录：`/Users/neal/Desktop/180day/数据库/数据库_PDF`。

- **TI《信号链基础知识合辑(1-10)》**：目录按运算放大器、ADC、Flash/管线/SAR/ΔΣ 转换器分开，且在运放部分强调 CMRR、偏置电流等与应用相关的指标。
- **TI《德州仪器高性能模拟器件 ADC》**：将 ADC/DAC、基准、放大器、ADC 驱动和接口分为独立设计/选型主题。资料特别指出：SAR ADC 驱动需同时考虑采样速度与外部信号源内阻；ADC 输入的开关电容特性会影响放大器稳定性与隔离电阻设计。
- **思瑞浦《模拟产品选型册 2024》**：实际产品族按运放、仪表放大器、电流检测、比较器、模拟开关、CAN/LIN/RS-485、隔离器件、LDO/基准、DC/DC、栅极驱动等分组；说明这些类别不应共用同一套对比维度。
- **ADI 官方 ADC 资料**：ADC 的采样、转换、数字接口与延迟专项依据见 [adc-timing-comparison.md](adc-timing-comparison.md)。

## 规则：共性层 + 类别专项层

所有器件共同核验：型号/版本、封装尺寸、引脚功能、绝对最大额定值、推荐工作范围、温度等级、认证/可靠性、状态/生命周期。

在此基础上，按下列类型追加专项核验；“相同引脚”不能跳过专项表。

| 类别 | 必比维度 | 直接替代的常见阻断项 |
| --- | --- | --- |
| 运放 / 仪表放大器 / 电流检测放大器 | 电源、输入共模、输出摆幅与负载、闭环稳定性、GBW、压摆率、Vos/漂移、噪声、偏置电流、CMRR/PSRR、使能 | 输入共模/输出摆幅不足；容性负载不稳定；增益/参考引脚语义不同 |
| 比较器 | 输入范围、传播延迟及测试 overdrive、迟滞、推挽/开漏输出、上拉、逻辑电平、锁存/使能、上电态 | 开漏与推挽不同；延迟测试条件不同；输出极性/默认态不同 |
| ADC | 采样触发、采集窗口、转换/BUSY/DRDY、延迟、同步、SPI/LVDS/JESD、启动配置 | 时序或数据帧不同；输入驱动不能在 acquisition 窗口内稳定 |
| DAC | 参考/输出范围、单调性、INL/DNL、建立时间/毛刺、负载、接口、默认码与 LDAC | 默认输出码、同步更新或参考方式不同；输出负载不兼容 |
| LDO | VIN/VOUT/电流、dropout 测试点、输出电容与 ESR、稳定性、Iq、PSRR、噪声、EN/软启动、保护/放电 | 电容/ESR 要求不同导致不稳定；EN 极性或放电路径不同 |
| DC/DC | 拓扑、VIN/VOUT/电流、频率、同步/扩频、外部电感与补偿、反馈、软启动/PG、保护、EMI | 外围功率器件/补偿网络不可复用；SW/FB/EN 引脚语义不同 |
| 电压基准 | 串联/并联、精度、温漂、噪声、负载/偏置电流、压差、启动、长期漂移 | 拓扑不同；负载范围或压差不满足；噪声影响系统精度 |
| 模拟开关 / MUX | 开关拓扑、信号范围、Ron/Ron flatness、漏电、寄生电容、带宽、开关时间、BBM、逻辑阈值、电荷注入 | 默认通道/BBM 不同；模拟信号超出新器件电源轨；逻辑不兼容 |
| CAN / RS-485 / LIN / RS-232 | 协议/速率、总线共模和故障电压、I/O 电平、延迟、EN/待机/唤醒、终端/失效保护、ESD/浪涌 | 总线耐压不足；待机/静默/唤醒引脚行为不同；CAN FD 等协议不支持 |
| 数字隔离器 / 隔离放大器 | 隔离认证/耐压、CMTI、方向、默认输出、数据率、延迟/skew、供电域、启动 | 隔离等级、方向或默认输出不同；skew/延迟破坏同步 |
| 栅极驱动器 | 拓扑、驱动电压、source/sink 电流、UVLO、延迟/死区、bootstrap、DESAT/Miller clamp、故障与关断 | 高低边/隔离方式不同；保护阈值或关断时序不同；外部 bootstrap 要求不同 |

## 实现策略

1. 从芯片型号与 datasheet 文字识别类型；允许多类别命中，例如 `isolated CAN transceiver` 同时使用接口和隔离模板。
2. 对每个命中的类别，将专项清单注入 LLM system prompt 和 user prompt，要求对应的“专项兼容性核验”表。
3. 原文找不到时固定输出“待核对 datasheet”，不让模型根据常识填值。
4. 类别识别只负责选择检查表，最终结论仍以 datasheet 事实为准。
5. 后续将这些模板迁移为可版本化的结构化 Schema，并记录每一项对应的数据手册页码。
